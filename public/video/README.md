# Hero avatar video

The hero checks for either `ateeqh-avatar-loop.webm` or `ateeqh-avatar-loop.mp4` in this folder. Add a short, portrait 4:5 talking-avatar clip here to replace the animated still. Keep it muted; the introduction voice is played separately by the page.

If neither clip exists or playback fails, the refined portrait remains visible with a slow camera drift and the voice introduction still works.

Recommended export: H.264 MP4 fallback, WebM when available, 720p or 1080p, 8-15 seconds, compressed for web delivery.
